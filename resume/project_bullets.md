# 游戏数据分析项目简历表述

## 推荐版

**Cookie Cats 首门槛 A/B 与留存分析｜个人项目**

- 基于 90,189 名玩家的公开 A/B 实验数据，使用 SQL 与 Python 分析首次付费门槛位置对 D1/D7 留存和游戏轮次的影响。
- 完成数据校验、Wilson 置信区间、双比例检验、异常值敏感性与轮次分群；发现 40 关组 D7 留存下降 0.82 个百分点（p=0.00155），据此建议保留 30 关门槛并补充付费指标验证。

## 面试展开版

- 业务问题：首次等待或付费门槛从第 30 关移到第 40 关，是否提升玩家参与度和留存。
- 数据口径：90,189 名新玩家，比较 `gate_30` 与 `gate_40` 两组。
- 分析过程：SQL 分组统计、留存率与置信区间、双比例检验、游戏轮次 P99 敏感性和分桶分析。
- 关键结论：40 关组 D7 留存从 19.02% 降至 18.20%，差异 -0.82 个百分点，95% CI 为 [-1.33, -0.31] 个百分点。
- 业务建议：保留 30 关门槛；如果业务仍希望验证后移门槛，需要补充 ARPU、付费转化和更长留存窗口。
